# JARVIS AI v0.9 — multilingvальный голос и навыки

### Что добавлено
- **Автоматическое определение и переключение языка** через Android 14 SpeechRecognizer: API 34 `EXTRA_ENABLE_LANGUAGE_DETECTION` и `EXTRA_ENABLE_LANGUAGE_SWITCH`. Языковой движок Android может игнорировать эти запросы, и не все языки/диалекты поддерживаются.
- **32 варианта настроек распознавания** (31 язык/диалект и «Автоматически») включая русский, украинский, узбекский, казахский, английский США/UK/Индия, испанский Испания/Мексика, арабский Саудовская Аравия/Египет, французский, немецкий, португальский, китайский, японский, хинди и другие. Выбор диалекта помогает уменьшить ошибки с акцентом, но не гарантирует распознавания любой речи.
- **Мультиязычная активация:** оригинальные написания и типичные варианты имени «Джарвис» на кириллице, латинице, китайском, японском, арабском, корейском и хинди. Включено использование нескольких гипотез распознавателя, а не только первой.
- **Базовые команды на разных языках:** время, дата, заряд на русском, английском, испанском, французском, немецком, китайском, японском и некоторых других. Голос Android TTS переключается на выбранный/определённый язык; Piper Dmitri используется только для русской речи.
- **Оригинальные Android-навыки:** таймеры, поиск в браузере, маршруты в картах — по мотивам модульного подхода Dicio и OpenVoiceOS. Эти сторонние проекты не скопированы в JARVIS: их GPL-исходники и отдельные зависимости не добавлялись.
- **Управление на нескольких языках:** открытие приложений, возврат на главный экран, прокрутка и набор текста с явным разрешением Accessibility.
- **ИИ отвечает на языке вопроса**: системная инструкция OpenAI обновлена, локальный маленький LLM тоже получает многоязычную инструкцию.
- Сохранены Fish Audio, Piper Dmitri, быстрый калькулятор, плавающее окно, Qwen как дополнительная офлайн-модель и окончание ответов «сэр».

### Настройка
1. Открой JARVIS → **ЯЗЫК И РАСПОЗНАВАНИЕ АКЦЕНТА**, выбери «Автоматически» или конкретный язык и акцент/диалект. Настройка применяется к следующим сеансам распознавания.
2. Запусти голосовой режим и произнеси «Джарвис, сколько время?», «Hey Jarvis, what time is it?», «Jarvis, quelle heure est-il?».
3. Установи языковые пакеты распознавателя Android/Google в системных настройках, если распознавание нужного языка не работает.
4. Для более сложного разговора на разных языках настрой OpenAI API. Без него применяется встроенная маленькая модель SmolLM2 или дополнительная Qwen2.5, которые **не обеспечивают свободное общение на всех языках**.
5. Языковые навыки: «таймер на 5 минут», «set timer 3 minutes», «найди в интернете...», «search for...», «маршрут до Казани», «navigate to Berlin». Эти действия открывают соответствующие приложения/системные экраны; возможны ограничения фонового запуска.

### Приватность, ограничения и лицензии
Это не гарантия «всех языков мира» и идеального понимания любого акцента. Реальный охват определяется распознавателем, установленными языковыми пакетами, акустикой, шумом и конфигурацией модели. Android SpeechRecognizer может использовать серверы поставщика службы распознавания. При использовании облачной модели вопросы уходят через OpenAI API; при Fish Audio текст ответа отправляется в Fish API для озвучивания. В автономном режиме эти сервисы не нужны, но для самого голосового ввода Android может использовать сеть.

Для управления экраном нужно вручную включить AccessibilityService; JARVIS не читает пароли и не подтверждает платежи. Фоновая активация словом «Джарвис» всё ещё зависит от Android SpeechRecognizer и может отключаться с экраном/из-за энергосбережения. Никакой гарантии круглосуточного hotword.

### Источники идей
- Dicio (GPL-3.0): https://github.com/DicioTeam/dicio-android — архитектура навыков, локальное распознавание, управление приложениями
- OpenVoiceOS: https://github.com/OpenVoiceOS/ovos-core — разделение намерений и навыков
- sherpa-onnx (Apache-2.0): https://github.com/k2-fsa/sherpa-onnx — используется в JARVIS для офлайн-синтеза речи, а не как универсальный ASR без дополнительных моделей
- Android Recognition API: https://developer.android.com/reference/android/speech/RecognizerIntent

### Установка и обновления
Для установки скачай app-debug.apk из GitHub Actions артефакта. Из-за подписи debug APK версии, построенные на разных GitHub runners, могут требовать переустановки. Для бесшовных обновлений нужно один раз настроить секреты стабильной подписи (см. предыдущий README/руководство GitHub), затем все будущие сборки выпускать с тем же сертификатом. Нельзя выкладывать закрытый ключ в публичный репозиторий.
