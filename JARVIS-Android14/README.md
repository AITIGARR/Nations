# JARVIS AI 0.8 — Android assistant

## Новое в v0.8
- Переработанное главное окно с компактным реактором, системным статусом, индикацией сети и доступа к управлению, быстрыми командами, расширенной историей чата и сворачиваемыми настройками. Плавающая панель стала контрастнее и получила кнопки Назад / Домой / Прокрутка.
- JARVIS обращается **«сэр»** во всех голосовых и текстовых ответах ассистента, независимо от источника (встроенные команды, OpenAI, SmolLM2, Qwen).
- Мгновенный локальный калькулятор с арифметикой, скобками, десятичными числами и процентами: «сколько будет 6 умножить на 7», «посчитай (2+3)*5», «20 процентов от 150». Не ждёт ответа нейросети и не использует сеть; ограничивает длину/сложность выражения.
- Команды управления Android через явно включённый AccessibilityService: «назад», «домой», «прочитай экран», «нажми на [название]», «прокрути вниз», «введи текст [фраза]», «очисти поле», «удали последний символ», «покажи/скрой клавиатуру».
- Ввод текста возможен лишь в активное редактируемое поле, куда пользователь предварительно поставил курсор. Приложение не вводит и не читает пароли, не записывает события/нажатия, не отправляет сообщения и не нажимает кнопки оплаты или подтверждения автоматически.
- Улучшена скорость обработки вычислений и управления: эти операции обрабатываются без LLM, Fish Audio и тяжелого Piper (используется быстрый системный TextToSpeech). При первом запуске TTS может понадобиться загрузка языкового пакета.

## Встроенные системы
- OpenAI API с контекстом переписки (требует личный API-ключ, интернет и может быть платным).
- Offline llama.cpp + SmolLM2, дополнительный более сильный Qwen2.5-0.5B (по кнопке).
- Fish Audio по собственному ключу; офлайн Piper Dmitri через sherpa-onnx; системная русская озвучка Android как запасной вариант.
- Плавающее окно поверх приложений и экспериментальная голосовая активация «Джарвис» через стандартный SpeechRecognizer.

## Реальные ограничения
Это пользовательский APK, а не системный сервис уровня фантастического фильма. Для ввода текста, чтения текущего экрана и нажатий **нужно явно разрешить JARVIS в «Специальных возможностях»**, а для наложения — «Показывать поверх других приложений». Некоторые поля/приложения не поддерживают Accessibility, фоновые запуски и микрофон ограничиваются Android 14/прошивкой. Нельзя обойти защищённые системы, экраны банков, подтверждения покупок и пароли. Постоянное пробуждение по имени с погашенным экраном текущим SpeechRecognizer не гарантируется.

### Как попробовать
1. Установите APK и разрешите «Показывать поверх других приложений». Для голосового режима разрешите микрофон, затем запустите прослушивание через приложение.
2. Для управления экраном отдельно включите JARVIS в специальных возможностях Android (если доверяете сборке). Android 13–14 может требовать отдельного «Разрешить ограниченные настройки» в карточке приложения.
3. Скажите: «Джарвис, сколько будет 123 умножить на 7?» — ответ должен прийти без нейросети. «Джарвис, открой Telegram», «Джарвис, введи текст Привет», «Джарвис, прочитай экран».
4. Для вопросов «объясни, что такое ...» используется онлайн OpenAI при наличии API-ключа, иначе офлайн-модель.

### Обновления вместо переустановки
Сохраняйте одинаковый applicationId, увеличивайте versionCode и подписывайте новые APK **тем же постоянным ключом**. Workflow поддерживает секреты `JARVIS_KEYSTORE_BASE64`, `JARVIS_STORE_PASSWORD`, `JARVIS_KEY_PASSWORD`, `JARVIS_KEY_ALIAS`. Если их нет, GitHub подписывает временным debug-ключом и следующая сборка может не установиться поверх предыдущей. Переход с уже установленного старого debug APK на постоянный ключ может один раз потребовать удаления приложения. Секреты и keystore не выкладывать в GitHub.
