# JARVIS AI v1.1 — звонки контактам

Новый навык: «Джарвис, позвони маме», «Джарвис, набери контакт Алексей», «Call John». JARVIS открывает локальный выбор телефонного номера по имени из адресной книги. Если найдено несколько совпадений, пользователь выбирает контакт. Каждый вызов требует отдельного подтверждения на экране.

Сценарий:
1. Из голоса в сервисе или через кнопку «Позвонить контакту» открывается защищённая страница звонков приложения.
2. Android запрашивает READ_CONTACTS при первом обращении. Контакты никогда не отправляются в OpenAI, Fish Audio или другие сервисы, не пишутся в лог и не сохраняются в настройках.
3. Номер и имя показываются пользователю; при нажатии «Позвонить» Android запрашивает разрешение CALL_PHONE и начинает звонок стандартным системным интерфейсом. При отказе JARVIS использует ACTION_DIAL — пользователь может вручную нажать вызов. Кнопка «Открыть набор» всегда остаётся доступна.
4. Для запуска страницы звонка голосом из фона Android может требовать разрешение на плавающее окно. В ином случае открой JARVIS и нажми кнопку «Позвонить контакту». Доступность службы специальных возможностей не требуется для звонков.

Это не перехват звонков: JARVIS не прослушивает и не записывает звонки, не читает журнал вызовов и не инициирует звонок без подтверждения пользователя. На планшете без SIM/приложения набора исходящий вызов может быть недоступен.

Сохраняются все функции v1.0, включая Qwen2.5-0.5B GGUF внутри APK, офлайн-голос Piper, Fish Audio, мультиязычное распознавание, навигацию и ввод в Android. Для обновления поверх старой версии Android требует совпадение сертификата подписи APK; GitHub Actions без постоянных секретов подписывает временным сертификатом, поэтому может понадобиться переустановка. Не удаляйте прежнюю версию до резервного сохранения API-ключей и настроек.

# JARVIS AI v1.0 — bundled Qwen2.5, Android screen control

## Что внутри APK
- Полная **Qwen2.5-0.5B-Instruct-Q4_K_M.gguf**, около 398 МБ (Apache 2.0). Вместо устаревшей встроенной SmolLM2; интернет/API-ключ для этой модели не нужны. Android-приложение копирует встроенный GGUF в приватную память при первом запуске офлайн-ИИ, после чего ответы локальные. Для копии нужен свободный объём около 470 МБ поверх места под APK.
- llama.cpp (MIT), с сохранением ранее загруженной GGUF в памяти процесса. Это ускоряет повторные вопросы, но первый запуск может длиться заметно дольше, а производительность зависит от процессора телефона. На слабых устройствах 0.5B по-прежнему может ошибаться.
- Fish Audio по личному ключу (онлайн), Piper Dmitri через sherpa-onnx (офлайн), системный TTS как резервный голос.
- Время/дата/заряд и калькулятор обрабатываются напрямую без обращения к модели.

## Управление Android через разрешение специальных возможностей
JARVIS может по **явным командам пользователя** открывать установленные приложения, листать вверх/вниз/влево/вправо, открывать уведомления, возвращаться назад/домой, нажимать видимые доступные элементы по тексту, вводить и очищать текст в заранее выбранном поле.

Новые команды:
- «Джарвис, покажи кнопки» — перечисляет до 12 доступных интерактивных элементов текущего экрана.
- «Джарвис, нажми номер 2» — нажимает второй элемент из заново построенного списка доступных безопасных элементов.
- «Джарвис, листай влево» и «Джарвис, листай вправо» — горизонтальные жесты.

**Технические ограничения:** доступ ко всем элементам экрана не гарантируется. AccessibilityService работает только если его разрешил пользователь и если другие приложения показывают семантические элементы в дереве доступности. Банки, менеджеры паролей, поля паролей, действия оплаты/отправки/удаления защищены; эти действия пользователь выполняет вручную. Не существует Android APK, способного безопасно и беспрепятственно контролировать абсолютно всё, как киношный JARVIS, без системных прав и ограничений производителя. Не обещаем работу на заблокированном экране.

## Распознавание речи
Автоматическое обнаружение/переключение языка Android 14 при поддержке установленного распознавателя; ручной выбор диалекта в JARVIS. Набор доступных языков зависит от Android SpeechRecognizer. Полное покрытие всех языков и акцентов не гарантируется.

## Обновление и подпись
App ID `com.horizon.jarvis`, versionCode 11. Чтобы устанавливать будущие версии поверх текущей, требуется **одинаковая стабильная подпись APK**. GitHub Actions использует секреты JARVIS_KEYSTORE_BASE64, JARVIS_STORE_PASSWORD, JARVIS_KEY_PASSWORD и JARVIS_KEY_ALIAS, если они добавлены в Secrets/Actions. Иначе применяется временная debug-подпись; обновление предыдущей версии может потребовать переустановки. Не публикуйте секреты.
