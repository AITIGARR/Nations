# J.A.R.V.I.S. AI — Android 14, v0.2

Оригинальный голосовой ИИ-помощник с плавающим окном поверх других приложений. APK для личного тестирования (debug сборка). Неофициальный проект, не связан с Marvel.

## Реализовано
- Тёмная киберпанк-панель, анимированный «реактор», оригинальная иконка приложения.
- Разрешение **показывать поверх других приложений** (Settings → Special app access → Display over other apps). Поверх всего появляется круглое перетаскиваемое окно; касание раскрывает панель диалога.
- Периодическое распознавание «Джарвис» и «Джарвис, [команда]» через SpeechRecognizer в foreground service (системный индикатор использования микрофона и уведомление). Для каждого обращения кнопку нажимать не нужно, но запуск фонового сервиса после перезагрузки/его остановки требует открытия приложения. Работа при выключенном экране и на всех прошивках не гарантирована.
- Контекст беседы в памяти текущего процесса до шести последних пар реплик.
- Онлайн OpenAI Responses API модель gpt-4.1-mini, задайте собственный API ключ в приложении; оплачивается отдельно. Ключ хранится через Android Keystore AES-GCM на самом телефоне, не в репозитории.
- AI-голос gpt-4o-mini-tts, голос onyx с оригинальными стилевыми инструкциями. Облачный голос включается тумблером; при отсутствии ключа или ошибке используется системный русский TextToSpeech. AI-голос сгенерирован и не является записью реального человека.
- Команды: время, батарея, YouTube, Telegram, Minecraft, настройки, браузер; запуск стороннего приложения через нажатие на системное уведомление (ограничение Android).
- Можно остановить прослушивание из главного окна, плавающей панели или системного уведомления. Нет root, Accessibility Service, скрытого микрофона или доступа к чужим данным.

## Установка и проверка
1. Перейдите на GitHub → Actions → **Build JARVIS Android 14 APK** в ветке **jarvis-android14**.
2. После успешного workflow скачайте artifact **JARVIS-Android14-debug-apk** и распакуйте app-debug.apk.
3. Установите debug APK на Android 14. При установке поверх прежней debug-версии может потребоваться удалить старую сборку, если различается подпись.
4. В приложении нажмите «РАЗРЕШИТЬ ПЛАВАЮЩЕЕ ОКНО» и выдайте разрешение на экран.
5. Разрешите микрофон и уведомления; нажмите «ЗАПУСТИТЬ ГОЛОСОВОЙ РЕЖИМ» один раз для запуска сеанса.
6. Сверните приложение — перетаскиваемый голубой круг должен остаться поверх других окон. Скажите «Джарвис, который час?».
7. Для общения с ИИ сохраните API ключ, попробуйте «Джарвис, объясни что такое нейросеть».
8. Голос AI можно отключить в главном окне для экономии API-расходов.

## Локальная сборка
Нужны JDK 17, Android SDK Platform 35 и Gradle 8.9:
    cd JARVIS-Android14
    gradle --no-daemon assembleDebug

## Ограничения и приватность
Это **не привилегированный системный ассистент**. Android 14 не разрешает стороннему приложению свободно управлять всеми окнами, нажимать в других приложениях без дополнительных разрешений или запускать микрофон-сервис из невидимого фона. Для фонового голосового сервиса требуется сначала явный запуск пользователем из видимого приложения. SpeechRecognizer не является непрерывным локальным hotword-движком и может отключаться из-за сети, ограничений прошивки, блокировки экрана и экономии энергии.

Произнесённые фразы передаются системному распознавателю речи Android; он может использовать сеть в зависимости от установленного движка. Вопросы, на которые отвечает ИИ, и текст ответов для AI-озвучки передаются OpenAI API. Контекст хранится только в памяти сеанса; реплики удаляются при остановке процесса. Облачные вызовы ИИ и озвучивания тарифицируются отдельно. Не включайте API ключ в репозиторий. Для публичного распространения лучше вызывать API через свой сервер, не передавая ключ прямо из клиентского APK.
