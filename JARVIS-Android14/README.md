# JARVIS AI 0.1 — Android 14

Первая тестовая версия голосового помощника для Android 14. Работает без root.

## Возможности
- Распознавание фразы «Джарвис» (через Android SpeechRecognizer) и голосовые ответы по-русски.
- Команды: время, заряд батареи, запуск YouTube/Telegram/Minecraft/настроек/браузера (через уведомление).
- Облачные ответы OpenAI Responses API, ключ вводится на устройстве и сохраняется через Android Keystore (AES-GCM).
- Работа микрофона через уведомление foreground-service с кнопкой остановки.
- Текстовые команды.

## Сборка
GitHub Actions на ветке \`jarvis-android14\` автоматически запускает Gradle и выгружает APK как artifact \`JARVIS-Android14-debug-apk\`. Сам APK внутри ZIP артефакта.

Локально: JDK 17, Android SDK 35, Gradle 8.9:
\`\`\`bash
cd JARVIS-Android14
gradle assembleDebug
\`\`\`

## Первый запуск
1. Установите debug APK и откройте JARVIS.
2. Дайте разрешение на микрофон и уведомления, нажмите «АКТИВИРОВАТЬ».
3. Скажите «Джарвис, который час?».
4. Для общих вопросов сохраните OpenAI API key (API оплачивается отдельно).
5. Завершайте работу через «ОСТАНОВИТЬ» или уведомление.

## Ограничения
Распознавание фразы не реализовано отдельным постоянным offline hotword-движком. Android SpeechRecognizer не гарантирует непрерывное фоновое распознавание, особенно с выключенным экраном. Для запуска приложений из фона Android может потребовать нажатия на уведомление. Это отладочная версия: Android SDK сборка и реальное устройство требуют проверки. Не вводите API-ключ в общедоступные файлы GitHub.
